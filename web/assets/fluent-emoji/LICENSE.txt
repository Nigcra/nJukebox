Fluent Emoji Color - bundled webfont
====================================

The emoji glyphs in assets/fluent-emoji/ are Microsoft's Fluent Emoji artwork,
converted to a COLRv1 webfont. They are bundled so the interface icons render
identically on Windows 10, Windows 11 and Linux instead of following whatever
emoji font the operating system happens to ship.

Artwork: microsoft/fluentui-emoji            https://github.com/microsoft/fluentui-emoji
Webfont: MARTYR-X-LTD/fluentmoji v1.0.0      https://github.com/MARTYR-X-LTD/fluentmoji
